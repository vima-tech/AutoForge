## [0.1.0] - 2026-08-09

Initial public alpha release.

### Highlights

- Human-gated workflow from requirement intake through implementation, tests,
  review and delivery.
- Local-first Tauri desktop application backed by SQLite.
- Pluggable Claude, Codex and OpenCode coding-agent runners.
- Isolated Git worktrees, controlled merge paths and traceable agent output.
- Project context, conversations, blueprint incubation, auditing and delivery
  views.
- Configurable LLM, MCP, search and notification integrations with encrypted
  local secret storage.
