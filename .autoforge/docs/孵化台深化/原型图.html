支付渠道接入与对账

背景与目标

现有 billing/ 仅记账，缺渠道抽象与对账。目标：接入微信/支付宝，日终对账并对差异告警。codegraph 佐证

功能范围

  • 统一渠道抽象 PaymentChannel（下单 / 查询 / 退款）
  • 对账文件拉取 + 与本地流水 diff
  • 差异分级告警（金额 / 状态 / 缺单）

非目标

  • 不做多币种；不接海外渠道

验收标准

  • 下单幂等：同一 out_trade_no 重复请求不重复扣款
  • 对账 T+1 生成差异报告，缺单/金额差 100% 命中告警
工具活动链
每条 assistant 气泡下挂一排 chip，显示 codegraph 检索 / read_file / read_spec 的命中数，让"它凭什么这么写"可见。
评估报告卡
落稿即自动评估，四维打分 + 待补强项。低于阈值会自动再修一版（上限 2 轮）。
来源标注
PRD 里由代码检索佐证的结论带 codegraph 佐证 标签，可追溯。
