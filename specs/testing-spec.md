# 测试规范（初级版本）

## 测试层级

### 单元测试
- 覆盖核心业务逻辑函数
- 外部依赖（LLM、短信 API 等）必须使用 mock
- 测试用例命名清晰表达测试意图

### 集成测试
- 验证核心功能路径（happy path）
- 验证关联模块无回归（相关接口返回期望状态码）
- 使用测试数据库，不依赖生产数据

## 通过标准
- 所有测试必须通过（零失败）
- 覆盖率不得低于项目配置的 min_threshold

## 缺陷报告格式

```
## 缺陷摘要
一句话描述问题

## 失败位置
文件：path/to/file.py 行：N

## 错误信息
[完整错误输出]

## 复现步骤
1. …
2. …

## 严重级别
Critical | High | Medium | Low

## 建议修复方向
[可选，如果原因明确]
```

## 误报处理
测试失败但怀疑是测试环境问题时，在报告中标注"疑似误报"并说明理由，由管理员决策。
