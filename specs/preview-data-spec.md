# 预览数据规范（初级版本）

## 最低数据完整性要求

每个预览环境启动时必须满足：
- 至少 1 个可用的管理员账号（用于预览登录）
- 核心业务实体存在足够数量（由各项目的 autoforge.yaml 声明）

## 数据质量要求

### 关联完整性
- 外键约束不得有悬空引用
- 树形结构（组织、分类等）必须有根节点

### 场景数据（由各项目声明）
- 必须包含能验证本次需求改动的数据场景
- 例如：测试"库存不足警告"需要包含库存为 0 的商品数据

## 脱敏要求

遵循 autoforge.yaml 中 `preview.sensitive_fields` 的声明：

| 规则 | 操作 |
|------|------|
| mask | 同格式占位符（手机 → `138****8888`，姓名 → `张*`） |
| hash | 不可逆哈希（保留唯一性） |
| drop | 清空为 NULL |

**执行时机**：seed 脚本运行后，容器健康检查前，执行一次全量脱敏。

## 数据库生命周期
- 每个 worktree 创建时独立生成预览数据库
- 命名规则：`preview_{project}_{cr_id}_{timestamp}`
- worktree 销毁时立即删除，不保留缓存
